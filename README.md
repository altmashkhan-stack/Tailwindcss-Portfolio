## 📖 Overview

This repository powers **Altmash Khan's** personal portfolio website — a clean, modern, single-page site that highlights a full-stack developer's tech stack, featured projects, work experience, and includes a standalone blog page. Built with **Tailwind CSS v4** using the new CLI-based workflow (no config file, utility-first styling compiled directly from `input.css` to `output.css`).

---

## 🚀 Features

- 🧑‍💼 **Hero Section** — Name, role, availability badge, and quick stats (experience, projects, clients)
- 🧰 **Tech Stack Showcase** — Organized into Frontend, Backend, and DevOps categories
- 💼 **Projects Section** — Highlighted work with descriptions
- 📈 **Experience Timeline** — Career history with companies and roles
- 📝 **Dev Blog** — Standalone blog page (`blog.html`) with technical write-ups (e.g. Docker explained)
- 📬 **Contact Section** — Email, GitHub, LinkedIn, Twitter links
- ⚡ **Tailwind CSS v4** — Latest CLI-based build pipeline, no `tailwind.config.js` needed
- 📱 **Fully Responsive** — Mobile-first, clean layout across all devices

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/altmashkhan-stack/Tailwindcss-Portfolio.git

# Navigate into the project folder
cd Tailwindcss-Portfolio

# Install dependencies
npm install
```

### Development

Run the Tailwind CLI in watch mode to compile styles automatically on change:

```bash
npm run dev
```

This watches `input.css` and regenerates `output.css` on every save.

### Preview

Simply open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
